# Weather-Data-Analysis-Project
# Overview
This project aims to analyze weather data to extract meaningful insights and address various business questions related to weather patterns. By leveraging Python's data manipulation libraries, we can uncover trends, identify unique values, and perform statistical analyses to support decision-making processes.
# Objectives
The key objectives of this analysis include:
Identifying Unique Values: Understanding the distinct wind speed values recorded in the dataset.
Weather Conditions Analysis: Quantifying occurrences of specific weather conditions, such as "Clear" and "Snow."
Handling Missing Data: Identifying and managing null values in the dataset.
Statistical Insights: Calculating mean, standard deviation, and variance for relevant weather parameters.
Conditional Filtering: Extracting records based on specific weather conditions and visibility metrics.
# Commands Used
We utilized several commands to perform various analyses on the dataset:
. head(): Displays the first N rows of the dataframe (default N=5).
. shape: Shows the total number of rows and columns in the dataframe.
. index: Provides the index of the dataframe.
. columns: Displays the names of each column.
. dtypes: Shows the data types of each column.
. unique(): Lists all unique values in a specified column.
. nunique(): Counts the total number of unique values in a column.
. count(): Counts non-null values in each column.
. value_counts(): Displays unique values with their occurrence count in a specified column.
. info(): Provides basic information about the dataframe.
# Insights
The analysis reveals:
. Most common weather conditions are "Mainly Clear", "Mostly Cloudy", and "Cloudy"
. Visibility averages 27.66 km with significant variation by weather condition
. Pressure remains relatively stable with low standard deviation
. Snow events occur in various combinations with other weather phenomena
. Extreme weather conditions show distinct patterns in temperature, humidity, and visibility
